台本の書き方
  • 話者：セリフ … 話者ごとに声を変えて読みます（: 半角でも可）
  • 話者のない行 … 「ナレーション」として読みます
  • [間 1.5] … 指定秒数だけ無音（[間] だけなら 1 秒）
  • （ト書き） … 行全体が括弧なら読み飛ばします（設定で読み上げも可）
  • # コメント … 読み上げません
