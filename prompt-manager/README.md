# プロンプト管理 Web アプリ

自分で入力したプロンプトを管理し、カンマ区切りで 1 つの文章に結合できる Web アプリです。
HTML / CSS / JavaScript のみで動作し、ビルドやサーバーは不要です。

## 機能

- **追加**：プロンプトを入力して追加（`a, b, c` のようにカンマ区切りで複数まとめて追加も可能）
- **修正・更新**：「修正」ボタン（またはテキストをダブルクリック）で編集し、「更新」または Enter で確定
- **削除**：個別削除・全削除
- **並べ替え**：↑ / ↓ ボタンで順番を変更
- **選択**：チェックを付けたプロンプトだけを結合（全選択 / 全解除）
- **結合**：区切り文字（`, ` / `,` / `、`）を選んで 1 つの文章に結合し、ワンクリックでコピー
- **セット保存**：結合結果に名前を付けて保存し、読込・更新・名前変更・削除が可能
- データはブラウザの `localStorage` に自動保存されます

## 使い方

公開版：https://syake1031.github.io/syake/

`main` ブランチに push すると GitHub Actions（`.github/workflows/pages.yml`）で自動的に GitHub Pages へデプロイされます。

ローカルでは `index.html` をブラウザで開くだけで使えます。

ローカルサーバーで動かす場合：

```sh
npx serve .
# または
python3 -m http.server 8000
```

## ファイル構成

```
index.html  画面
style.css   スタイル（ダークモード対応）
app.js      ロジック（追加・更新・削除・結合・保存）
```
